# SQL базы данных

Эта папка содержит все SQL файлы для настройки и управления базой данных проекта.

## 📋 Список SQL файлов

### Основные скрипты базы данных

- **`init_db.sql`** (8,151 bytes) - Основной скрипт инициализации базы данных
  - Создает все необходимые таблицы
  - Настраивает отношения между таблицами
  - Добавляет базовые данные (если есть)

- **`db.sql`** (6,695 bytes) - Структура базы данных
  - Определения всех таблиц с комментариями
  - Связи между таблицами
  - Индексы и ограничения

### Управление данными

- **`seed_data.sql`** (1,558 bytes) - Тестовые данные
  - Примеры данных для разработки и тестирования
  - Демо-курсы, пользователи и другие сущности

- **`sessions.sql`** (256 bytes) - Таблица сессий
  - Структура для хранения пользовательских сессий
  - Настройки аутентификации

### Администрирование

- **`drop_all_tables.sql`** (1,340 bytes) - Удаление всех таблиц
  - Полная очистка базы данных
  - ⚠️ **Использовать с осторожностью!**

## 🚀 Как использовать

### Инициализация базы данных

```bash
# Из корня backend
cd backend

# Запуск основного скрипта инициализации
psql -U your_username -d your_database -f sql_bases/init_db.sql

# Или через Node.js скрипт
node init_db.js
```

### Загрузка тестовых данных

```bash
# После инициализации базы данных
psql -U your_username -d your_database -f sql_bases/seed_data.sql
```

### Очистка базы данных

```bash
# ⚠️ ВНИМАНИЕ: Удалит все данные!
psql -U your_username -d your_database -f sql_bases/drop_all_tables.sql
```

## 📊 Структура таблиц

Основные таблицы в базе данных:

### Пользователи и аутентификация
- `users` - Основная таблица пользователей
- `profiles` - Профили пользователей (расширенная информация)
- `sessions` - Активные сессии пользователей

### Контент
- `courses` - Курсы обучения
- `sections` - Разделы курсов
- `lessons` - Уроки в разделах
- `course_categories` - Категории курсов

### Прогресс и взаимодействие
- `user_enrollments` - Записи о регистрации на курсы
- `user_lesson_progress` - Прогресс прохождения уроков
- `favorites` - Избранные курсы пользователей

### Календарь и события
- `calendar_events` - События календаря
- `event_attendees` - Участники событий

### Социальные функции
- `achievements` - Достижения пользователей
- `user_achievements` - Полученные достижения

### Системные таблицы
- `activity_logs` - Логи активности пользователей
- `app_settings` - Настройки приложения
- `user_settings` - Настройки пользователей

## 🔧 Конфигурация подключения

Файлы используют следующие настройки подключения (из .env):
- **DB_USER**: Пользователь базы данных
- **DB_PASSWORD**: Пароль
- **DB_NAME**: Название базы данных
- **DB_HOST**: Хост (по умолчанию localhost)
- **DB_PORT**: Порт (по умолчанию 5432)

## 📈 Разработка

При внесении изменений в структуру базы данных:
1. Обновите соответствующий SQL файл
2. Протестируйте изменения на копии базы данных
3. Обновите этот README при добавлении новых таблиц
4. Создайте миграции для продакшена

## 🔒 Безопасность

- Никогда не коммитте реальные пароли в репозиторий
- Используйте .env файлы для конфиденциальной информации
- Регулярно создавайте резервные копии базы данных
