# Тесты Backend

Эта папка содержит все тестовые файлы для проверки функционала backend приложения.

## 📋 Список тестовых файлов

### Основные тесты API

- **`test-calendar-api.js`** - Основной тест для API календаря
  - Тестирует аутентификацию и создание задач в календаре
  - Использует существующий аккаунт `calendar_test@example.com`

- **`test-auth-signup.js`** - Тест регистрации пользователей
  - Проверяет endpoint `/api/auth/signup`

- **`test-signup.js`** - Альтернативный тест регистрации

### Диагностические тесты

- **`debug-auth.js`** - Детальная диагностика аутентификации
  - Проверяет сессии, куки и защищенные маршруты

- **`diagnose-issues.js`** - Диагностика проблем с сервером и БД
  - Проверяет подключение к серверу и базе данных

### Утилиты

- **`cleanup-test-data.js`** - Очистка тестовых данных из БД
  - Удаляет тестовых пользователей и задачи

- **`test-db.js`** - Тест подключения к базе данных

- **`test-server.js`** - Тест запуска сервера

- **`test-with-server.js`** - Комплексный тест с автоматическим запуском сервера

## 🚀 Как использовать

### Запуск отдельного теста

```bash
# Из корня backend
cd backend

# Запуск основного теста календаря
node tests/test-calendar-api.js

# Диагностика аутентификации
node tests/debug-auth.js

# Очистка тестовых данных
node tests/cleanup-test-data.js
```

### Автоматический запуск с сервером

```bash
# Запуск сервера + теста календаря
node tests/test-with-server.js
```

### Диагностика проблем

```bash
# Проверка сервера и БД
node tests/diagnose-issues.js
```

## 📊 Структура тестов

Каждый тест следует следующей структуре:

1. **Подготовка данных** - создание тестовых пользователей/данных
2. **Выполнение запросов** - HTTP запросы к API
3. **Проверка ответов** - валидация статус кодов и данных
4. **Очистка** - удаление тестовых данных (опционально)

## 🔧 Конфигурация

Тесты используют следующие настройки:
- Сервер: `http://localhost:3002`
- Тестовый аккаунт: `calendar_test@example.com`
- Пароль: `testpassword123`
