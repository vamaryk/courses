# Введение в машинное обучение

Машинное обучение (Machine Learning) — это область искусственного интеллекта, 
которая позволяет компьютерам обучаться на данных без явного программирования.

## Основные понятия

### Модель
Модель — это математическое представление данных, которое используется для 
предсказания или классификации. Модель обучается на тренировочных данных и 
затем применяется к новым данным.

### Датасет
Датасет (Dataset) — это набор данных, используемый для обучения и тестирования 
модели. Обычно делится на тренировочную и тестовую выборки.

### Нейронная сеть
Нейронная сеть — это модель, вдохновлённая биологическими нейронами мозга. 
Состоит из слоёв нейронов, соединённых весами.

Пример простой нейронной сети на Python:
```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 128),
    nn.ReLU(),
    nn.Linear(128, 10)
)
```

### Функция потерь
Функция потерь (Loss Function) — это метрика, измеряющая ошибку модели.
Цель обучения — минимизировать функцию потерь.

Примеры:
- MSE (Mean Squared Error) — для регрессии
- Cross-Entropy — для классификации

### Градиентный спуск
Градиентный спуск — это алгоритм оптимизации для минимизации функции потерь.
Он вычисляет градиент и обновляет веса в направлении уменьшения ошибки.

### Переобучение
Переобучение (Overfitting) — это ситуация, когда модель слишком хорошо запоминает 
тренировочные данные, но плохо обобщает на новые данные.

Методы борьбы:
- Dropout
- Регуляризация (L1, L2)
- Аугментация данных

## Типы машинного обучения

### Обучение с учителем
Обучение с учителем (Supervised Learning) — модель обучается на размеченных данных, 
где каждый пример имеет правильный ответ (метку).

### Обучение без учителя
Обучение без учителя (Unsupervised Learning) — модель находит паттерны в данных 
без меток. Примеры: кластеризация, уменьшение размерности.

### Обучение с подкреплением
Обучение с подкреплением (Reinforcement Learning) — агент обучается через 
взаимодействие со средой, получая награды за правильные действия.
